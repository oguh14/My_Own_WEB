# Portafolio de HugoG

Portafolio web personal de un desarrollador junior que empieza como freelance. Presenta mi perfil, las tecnologías que uso, tres proyectos de ejemplo, los servicios que ofrezco y cómo contactar conmigo.

**Web:** [https://oguh14.github.io](https://oguh14.github.io/My_Own_WEB/)

## Sobre mí

Estudiante del ciclo superior de Desarrollo de Aplicaciones Multiplataforma (DAM). Trabajo con Java, Python, JavaScript, HTML y CSS, y estoy aprendiendo C y C++.

## Contenido de la web

- Presentación, sobre mí y tecnologías (las que uso y las que estoy aprendiendo).
- Tres proyectos de ejemplo, con vista previa, demo y código fuente visibles en la propia página:
  - Web para un negocio local (negocio ficticio).
  - Gestor de gastos por consola, en Java.
  - Calculadora de presupuesto (precios ficticios).
- Servicios, proceso de trabajo y formulario de contacto.

## Tecnologías

HTML, CSS y JavaScript, sin frameworks ni dependencias. Solo se carga la tipografía desde Google Fonts. Toda la web está en un único archivo, `index.html`.

## Formulario de contacto

No hay servidor. El formulario prepara el mensaje y lo abre en Gmail, Outlook o en la aplicación de correo del visitante, o permite copiarlo. El envío lo hace siempre la persona que escribe.
